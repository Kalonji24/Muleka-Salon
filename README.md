# Muleka Salon 

A modern, responsive website for Muleka Salon - Bellville's premier hair studio specializing in hair styling, coloring, treatments, and more.

## Features

- **Responsive Design** - Works perfectly on all devices (mobile, tablet, desktop)
- **Interactive Booking System** - Book appointments via WhatsApp or Email
- **Image Carousels** - Smooth scrolling galleries for signature looks and portfolio
- **Mobile-Friendly Navigation** - Burger menu for easy mobile browsing
- **Smooth Animations** - Elegant hover effects and transitions
- **Contact Integration** - Direct WhatsApp, phone, and email links

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts (Playfair Display, Jost)
- SVG Icons

## How to Use

1. Clone the repository
```bash
git clone https://github.com/yourusername/muleka-salon.git
```

2. Open `index.html` in your browser

3. Customize the content:
   - Update images in the `/images` folder
   - Modify contact details (phone, email, address)
   - Adjust prices and services as needed
   - Update color scheme in `styles.css`

## Customization

To customize for your own salon:

1. **Update Contact Info**: Change phone number, email, and address in HTML
2. **Change Colors**: Modify CSS variables in `styles.css`
3. **Add Your Images**: Replace placeholder images in `/images` folder
4. **Update Services**: Edit service names, descriptions, and prices
5. **Modify Hours**: Update business hours in footer section
